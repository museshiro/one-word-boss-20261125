One word describing my boss, for the [make.fun bounty](https://make.fun/bounty/u-swift-badger-44-one-word-for-the-boss-6b48c735).

## The word

**Escalator** — nine characters, one word, no spaces.

He escalates every decision upward instead of making it, and like the
machine, he only ever goes up — while the rest of us stay on the same floor.

## How it works

`main.ts` writes the word to `entry.txt` (and to `/output/entry.txt` when the
grader sandbox provides it). Run it with Node 22:

```sh
node main.ts
```
